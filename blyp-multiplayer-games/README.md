## Overview

The Blyp Multiplayer Games project includes several fun and interactive games that allow users to connect and compete with friends. The games are designed to be easy to play and provide a seamless experience for users.

## Game Types

1. **Tic Tac Toe**: A classic game where players take turns marking a space in a 3x3 grid. The first player to align three marks horizontally, vertically, or diagonally wins.
2. **Word Guess**: A word-guessing game where players try to guess a hidden word by suggesting letters within a limited number of attempts.
3. **Quick Draw**: A drawing game where players compete to draw a given prompt as quickly and accurately as possible.

## Installation

To get started with the Blyp Multiplayer Games project, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/blyp-multiplayer-games.git
   ```
2. Navigate to the project directory:
   ```
   cd blyp-multiplayer-games
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the project, use the following command:
```
npm start
```
This will start the development server, and you can access the app on your device or emulator.
