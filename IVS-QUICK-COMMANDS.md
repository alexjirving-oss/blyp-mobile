# IVS Real-Time Wiring - Quick Command Reference\n\n## ONE-TIME SETUP (AWS)\n\n```powershell\n# 1. Create a Stage\naws ivs-realtime create-stage --name blyp-dev --region us-east-1\n\n# Copy the stageArn from output (looks like: arn:aws:ivs:us-east-1:123456789012:stage/AbCdEfGhIjKl)\n```\n\n## CONFIGURATION (Local)\n\n```powershell\n# 2. Edit .env.ivs-local\nEdit .env.ivs-local\n\n# Fill in:\n# AWS_ACCESS_KEY_ID=AKIA...\n# AWS_SECRET_ACCESS_KEY=...\n# AWS_REGION=us-east-1\n# IVS_STAGE_ARN=arn:aws:ivs:us-east-1:123456789012:stage/AbCdEfGhIjKl\n# IVS_DEV_BYPASS=\n```\n\n## DEVELOPMENT (Every session)\n\n### Option A: Automatic (Recommended)\n\n```powershell\n# From repo root\n.\\start-ivs-dev.ps1\n```\n\n### Option B: Manual\n\n**Terminal 1 - IVS Backend:**\n```powershell\n$env:AWS_ACCESS_KEY_ID='AKIA...'\n$env:AWS_SECRET_ACCESS_KEY='...'\n$env:AWS_REGION='us-east-1'\n$env:IVS_STAGE_ARN='arn:aws:ivs:us-east-1:123456789012:stage/AbCdEfGhIjKl'\n$env:IVS_DEV_BYPASS=''\nnode local-ivs-server.js\n```\n\nExpect to see:\n```\n✅ [IVS_LOCAL] Real IVS tokens: ENABLED\n```\n\n**Terminal 2 - Metro:**\n```powershell\n$env:EXPO_PUBLIC_API_BASE_URL='http://192.168.1.236:3001'\n$env:EXPO_PUBLIC_STREAMING_BACKEND='IVS'\nnpx expo start --dev-client --clear\n```\n\n## TESTING\n\n1. Open Blyp dev build on Galaxy Z Fold\n2. Go to Live tab\n3. Tap **Go Live**\n4. Enter title → **Start**\n\nExpect:\n- App logs: `DEV_BYPASS_ENABLED: false`\n- App logs: `issuedBy: \"aws\"`\n- Connection: `idle → connecting → connected`\n\n## VERIFICATION\n\n### Backend logs should show:\n```\n✅ [IVS_LOCAL] Real IVS tokens: ENABLED\n   AWS credentials: set\n   AWS SDK: loaded\n   Stage ARN: arn:aws:ivs:...\n\n[HOST_START] ✓ Success - returning token for user blyp (issued by: aws)\n```\n\n### App logs should show:\n```\n[IVS_API][CONFIG] {\"API_BASE_URL\": \"✓ set\", \"DEV_BYPASS_ENABLED\": false}\n[IVS_API][HOST_START] {\"bypass\": false}\n[IVS_HOST][TOKEN_RECEIVED] {\"stageArn\": \"arn:aws:ivs:us-east-1:...\", \"streamId\": \"stream-...\"}\n[IVS_CLIENT] Starting host session\n[IVS_STAGE] Connection state: CONNECTING\n[IVS_STAGE] Connection state: CONNECTED\n[IVS_STAGE] Participant joined: id=..., local=true\n```\n\n## COMMON ISSUES\n\n**Backend says \"Real IVS tokens: DISABLED\"**\n- Check: `.env.ivs-local` has non-placeholder values\n- Check: `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` are set\n- Check: `IVS_STAGE_ARN` is set (not empty, not \"REPLACE_WITH_...\")\n- Check: `npm install @aws-sdk/client-ivs-realtime` was run\n- Check: `IVS_DEV_BYPASS` is empty (not set to \"1\")\n\n**App still says \"connecting\" forever**\n- Confirm: Backend logs show `Real IVS tokens: ENABLED`\n- Confirm: Backend logs show `issued by: aws` (not mock)\n- Confirm: App logs show token `issuedBy: \"aws\"`\n- Confirm: Metro logs show `DEV_BYPASS_ENABLED: false`\n- Check: Stage ARN region matches `AWS_REGION` (both `us-east-1`)\n\n**\"ECONNREFUSED\" on 192.168.1.236:3001**\n- Backend not running?\n- Wrong IP?
