# Blyp Verification Matrix

## Purpose
Turn high-impact unknowns into explicit evidence gates so each item can move only through:
`Reported` -> `Reproduced` -> `Verified Fixed`.

## Gate Rules
1. `Reproduced` requires objective evidence captured in a dated artifact path.
2. `Verified Fixed` requires a post-change rerun on the same gate with explicit pass evidence and no contradictory fresh failures.
3. Human-check-only notes are not enough for `Verified Fixed` unless the matrix row explicitly allows `Limited` and names the allowed human check.
4. If a proof path does not exist yet, record it as a gap. Do not infer success.
